# Portafolio Web - Scarlett Castillo

## Descripción

Este proyecto consiste en el desarrollo de un portafolio web personal, creado para presentar mi perfil como estudiante de Programación, mis habilidades, estudios, proyectos e intereses relacionados con la tecnología.

El sitio utiliza una estética moderna con una combinación de colores oscuros y tonos burdeos, además de animaciones y elementos interactivos. También cuenta con un diseño responsive, adaptado para distintos tamaños de pantalla como computadores, tablets y celulares.

## Tecnologías utilizadas

* **HTML5:** estructura y contenido de las distintas secciones de la página.
* **CSS3:** diseño visual, colores, animaciones, efectos y adaptación a distintos dispositivos.
* **JavaScript:** interactividad, animaciones al hacer scroll, formulario, botón para volver arriba y otras funcionalidades.
* **Bootstrap 5:** framework utilizado como apoyo para el diseño responsive, componentes y estructura de la página.
* **Bootstrap Icons:** biblioteca utilizada para incorporar iconos al portafolio.
* **Git:** control de versiones y seguimiento de los cambios realizados durante el desarrollo.
* **GitHub:** almacenamiento del repositorio y publicación del proyecto mediante GitHub Pages.

## Secciones del portafolio

* **Inicio:** presentación personal y acceso a las principales secciones del portafolio.
* **Sobre mí:** información sobre mi perfil como estudiante de Programación, mis intereses y objetivos.
* **Proyectos:** muestra de proyectos desarrollados durante mi aprendizaje.
* **Habilidades:** presentación de mis conocimientos técnicos y habilidades personales.
* **Estudios:** información sobre mi formación académica.
* **Contacto:** formulario y datos para poder comunicarse conmigo.

## Proyectos
